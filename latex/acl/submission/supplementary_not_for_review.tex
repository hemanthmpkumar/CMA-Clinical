\section{Data Availability Statement}

All datasets used in this study are publicly available:

\begin{itemize}
  \item \textbf{MIMIC-III} (v1.4): \url{https://physionet.org/content/mimiciii/}
  \item \textbf{MIMIC-IV} (v2.2): \url{https://physionet.org/content/mimiciv/}
  \item \textbf{eICU Collaborative Research Database} (v2.0):
        \url{https://physionet.org/content/eicu-crd/}
  \item \textbf{HiRID} (v1.1.1): \url{https://physionet.org/content/hirid/}
\end{itemize}

Access requires PhysioNet account registration and signing of the respective
data use agreements. No new data were generated in this study.

Upon acceptance of this manuscript, the authors commit to:

\begin{enumerate}
  \item Release all evaluation code, model weights, and configuration files on

  \item Maintain a public issue tracker for reproducibility questions for a

\section{Open Science Framework Pre-registration}

Pre-registered analysis plan is deposited at the Open Science Framework (OSF).
The OSF record includes:
\begin{itemize}
  \item Pre-specified primary and secondary outcomes (as reported in Section~IV
        of the manuscript)
  \item Pre-specified statistical analysis plan (Wilcoxon signed-rank tests,
        $\alpha{=}0.05$, Cohen's $d$)
  \item Pre-specified four-arm crossover design parameters
  \item Date of pre-registration: prior to data analysis
\end{itemize}
