Data generated by such devices can be exploited using advanced mechanisms, in order to avoid critical situations or even death, due to worsening of pre-existing conditions. This way, it is possible to provide a valid system to support nursing activities, with powerful tools that, through continuous monitoring, address priorities to solve critical situations. Focusing on enabling efﬁcient health monitoring within hospital premises, this paper proposes a smart solution to monitor the well-being of patients. The main idea is therefore to design an ICT system able to man- age and conﬁgure wearables and other useful IoT resources, equipped with sensors probing physiological parameters. In this arrangement, such IoT devices are able to exchange data with a Cloud platform, while equipped with enough resources to run optimized Machine Learning (ML)-based workloads locally, when needed. In particular, our idea is to provide a monitoring system meant to be up and working in next to no time. The aforementioned achievement is possible thanks to limited prerequisites to activate inference, albeit with sub- optimal (initial) accuracy, and able to steadily improve capabil- ities and efﬁciency over time using a Distributed Incremental Learning (DIL) approach applied to ML techniques. Indeed, the system supports automatic updates for ML models running on wearable IoT devices thanks to the robust mechanisms for remote code injection provided by Stack4Things, an I/Ocloud- driven Things-as-a-Service platform [3].
